# PTE Speaking Lab：`1.0` → `v1.99` 变更记录

日期：2026-09-26。`1.0` 固定在提交 `63e55cebfac53d9c00888332ab15ddfda554d0cb`；`v1.99` 标记下列功能与文档更新后的版本。本文件记录两标签之间的变化，早期实验数据仍见 [MVP 验收记录](MVP_ACCEPTANCE.md) 和 [开发进度](../progress.md)。

## 产品与输入

| `1.0` 基线 | `v1.99` |
|---|---|
| 两侧需提供复制的猩际转写，截图用于映射逐词颜色。 | 猩际截图优先：一次识别生成可编辑的实际转写和红黄绿候选；复制转写可选，用于提示差异。支持粘贴剪贴板图片或选择文件。 |
| 共同计划朗读原文以文本输入。 | 还可粘贴或上传完整英文朗读稿截图，OCR 结果在提交前可编辑；DI 图表不能替代朗读稿。 |
| 未人工复核的词色不进入首次发音分析。 | 可靠映射的截图颜色标为 `candidate`，默认显示并以较低证据质量参与首次分析；无法确定的词仍为 `unknown`，以红色 `!` 提醒。人工确认或修改后为 `confirmed`。 |

原图、OCR 草稿、可选复制稿、最终文本、来源及修订分别保存；旧分析报告仍绑定原双边修订，不因后续改色而改变。用户录音与上传的 AI 高分参考录音分别保留分数和实际转写；两侧个别词和尾部不同不会自动算作发音错误。Content 仍只保存猩际分数。

## 分析、报告与体验

- OpenPronounce 已安装时，运行页默认开启本地音素候选，可关闭。它是未经校准的额外线索，首次下载模型可能显著变慢；失败时其余测量仍保留。
- 流利度表格统一说明“无法判断”及证据质量，表格下方用中文解释 WPM／每分钟词数、双边差值和有效指标；重复、重启、填充词等当前缺可信检测时不伪称可通过开关启用。
- CLIProxyAPI 可通过 OpenAI-compatible Chat Completions 接口改写已有的训练建议。每次分析需显式勾选；模型不能改动 finding/证据 ID 或原建议中的数字。报告显示是否采用 AI 文案，并可展开查看改写前的本机建议；失败时回退规则。官方 OpenAI 路径保留。
- 证据时间轴修复了前端仅展示前 120 条造成的录音尾部不可见问题。`Choices of Lunch` 的 428 条有时间戳证据现可全部查看；另有 30 条无可靠时间戳，页面明确说明。默认聚焦用户红黄词，展示前后各三个词；能按共享原文位置配对时展示 AI 同词上下文。两侧各有长片段与“目标词加左右各一词”的短片段回听。可切换到完整时间轴，保留录音时间顺序、用户红黄底色与尾部跳转。
- 时间轴移到双边录音面板之后，并有始终可见的快捷入口。页面内的两侧播放器互斥，点击另一侧播放、逐词或证据回听时先暂停当前声音。

## 部署、数据与修复

- 新增 `scripts/start.sh`、`stop.sh`、`restart.sh`，用 macOS `launchd` 管理受密码保护的内网服务。网页、API 和录音同源提供；当前本机配置监听 `192.168.5.14:8765`。后台服务显式设置 Homebrew 路径，解决 `launchd` 找不到 FFmpeg/ffprobe 导致分析失败；停止脚本等待服务注销，避免快速重启竞态。
- 数据库迁移 `0005` 增加朗读稿截图/OCR 来源与 `candidate` 词色状态；`0006` 修复部分既有数据库已登记迁移但词色表仍保留旧 CHECK 约束的问题，保留已有词记录。迁移前曾备份本机数据库，备份文件未入库。
- 原始音频、截图、SQLite、模型缓存、`.env` 和私人测试包继续由 Git 忽略。内网所有登录者共用数据；应用不提供账户隔离。HTTP Basic 仅适合可信内网，另一台设备访问和路由器 DHCP 固定租约仍需在现场验证。

## 验证与限制

- 后端测试：**38 passed**；前端 TypeScript 检查与生产构建通过。
- `Choices of Lunch` 的真实报告验证了双边 AI 改写、时间轴首尾、红黄词双边上下文、切换完整证据、回听入口及互斥播放。内网服务本机地址验证：未授权返回 401，授权首页与健康检查返回 200。
- 当前截图 OCR 只实测浅色整页猩际版式；截图停顿符号尚未可靠映射。VAD、词级对齐和 OpenPronounce 仍可能不可靠，相关指标会降级；音素线索不能解释猩际评分机制或代替人工核查。
- `v1.99` 是项目版本标签，不代表官方 PTE 评分器已完成，也不代表所有候选词色都已人工复核。
