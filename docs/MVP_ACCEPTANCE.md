## 降级、证据与数据安全

- Pronunciation 和 Fluency 引擎分别独立测试；合成已确认颜色样本产生红词 Finding，引用的证据 ID 均存在。停用对齐时不伪造词时间戳；若 VAD 可信，音频级 WPM/停顿仍可计算。
- 真实录音的 WebRTC VAD 内部区间质量不足，因此语音/静音比不可用、词间隔停顿只作低质量候选。重复、false starts、fillers 没有可信口误标注时显示不可判断。
- 旧报告保留原双边修订；修改 Content 分后旧报告不变。无独立 OpenAI API key/模型时云端分析返回可修正错误，不创建分析运行；前端 Provider 设置只返回配置状态，不返回 key。真实 OpenAI 网络调用尚未执行。
- 删除比较前展示记录和专属文件；自动化测试验证共享录音与截图在另一比较仍引用时不会删除。
- `.env`、`data/`、`测试数据包/` 和本地模型均被 Git 忽略。数据库资产使用相对路径；迁移步骤见 [README.md](../README.md)。

## 2026-09-26 截图优先改造复验

上表记录的是改造前的 `analysis-v2`。新流程已用同一组私有双边样本从截图直接提取转写与词色，分别得到 **99/99**、**111/111** 个候选词且未知数为 0；复制转写可以省略或与 OCR 稿不同。共同朗读稿截图可识别为可编辑文本，粘贴图片入口已在浏览器触发。候选词色以低可信度参与首次分析，历史报告保持原输入快照。

`analysis-v3` 重跑后词级对齐分别为 **91/99**、**106/111**，WPM 为 **151.43**、**169.8**；OpenPronounce 音素候选分别产生 **6**、**9** 项。首次默认 OpenPronounce 运行包含网络模型下载，用户侧耗时约 **692 秒**；模型缓存后参考侧耗时约 **3.72 秒**。浏览器验收确认：证据时间轴按录音时间递增，用户红黄词有对应底色；流利度表格仅显示“无法判断”，上方统一解释原因，下方显示中文总结。后端 **28 passed**，前端生产构建通过。截图候选仍需要人工校准才能提高发音结论的可信度。
