# TTS 练习参考：实现、验证与限制

更新：2026-09-27。`2.0` 标签固定在本功能改造前的 `29f6cf6`。本文件描述后续新增的独立 TTS 入口。

## 使用流程

从首页或导航进入 `/comparisons/tts/new`。输入完整英文朗读稿，或粘贴/选择朗读稿截图并校对 OCR；预览可编辑的语义断句，选择音色和语速。上传**我的回答**录音、猩际截图并填写我的三项分数。后端在线生成参考 WAV 后保存 Comparison，用户可复核截图词色、运行分析、在报告中按词回听。历史页默认“全部”，可筛选“上传参考”和“TTS 参考”。旧的双边上传入口保持原样。

## 技术流程

1. `POST /api/v1/tts/segments` 根据句末标点、段落拆分；长句才在逗号或词边界继续拆。用户修改后的各段是最终合成脚本。
2. `POST /api/v1/tts/generations` 对各段依次请求在线 Edge TTS 的 MP3 与 WordBoundary。每段限时 `TTS_TIMEOUT_S`，失败仅重试一次。需要网络；不使用 OpenAI/CLIProxyAPI key。
3. FFmpeg 解码为 24 kHz 单声道 PCM。按实际 PCM 样本数计算每段全局偏移，将 WordBoundary 转为合成 WAV 起点的秒数。分段边界的自然安静区不足 `TTS_GAP_MS` 才补零；每个边界都保存为 seam，避免当成真实朗读停顿。
4. SQLite `tts_generations` 保存脚本、分段、音色、语速、词时间、接缝、provider 版本与音频资产 ID；WAV 存在相对路径中。相同参数和版本可命中缓存。`ResponseSample.audio_origin=edge_tts`、`transcript_source=tts_script`，TTS 侧分数、颜色和截图为空。
5. 分析时用户侧仍做原有音频准备/对齐；TTS 侧仅对与脚本严格同词、同顺序的 WordBoundary 建立可信时间。Pronunciation 和 Fluency 仍独立运行，比较层仅比较可用的指标与共享词。生成接缝附近的停顿从候选中排除；整体 WPM 仍包含分段时间，需低质量解释。旧报告不变。

## 已验证

- `Choices of Lunch` 的真实 191 词朗读稿用 `en-US-AriaNeural`、默认语速生成 10 段合成 WAV；获得 191 个词时间事件、9 处接缝。新样本比较为 `comparison_aa38aa7d40294450ab68ec37fb64cd93`，重跑报告 `run_0817844b3ebe43d1908625a3506f7bd8`：TTS 侧 191/191 词定位，用户侧 181/186 词定位；接缝没有被算成 TTS 停顿。该运行是本机真实数据验证，数据文件不入库。
- 自动化测试覆盖断句、时间偏移、缓存、接缝排除、文本与边界不一致时的降级；现有上传比较的测试也继续执行。

## 边界与后续

- TTS 是在线合成的**练习参考**，不是猩际高分录音、真人标准发音或官方分数。生成文本会发送到 Microsoft 在线服务；用户录音不会交给该服务。TTS 侧无独立 ASR，也无猩际逐词颜色或分数，因此报告不做双边词色优劣判断。
- WordBoundary 由合成服务返回，准确性未经独立标注集校准；服务改变发音或标点处理时可能与脚本不符，相关词会降级。脚本分段采用标点和长度规则，用户应在生成前审查语义停顿。
- 接口为同步生成；在线服务超时或断线时可重试，页面输入保留。未实现后台队列、进度百分比、断点续传。较长脚本仍可能等待几十秒；生成成功但之后保存比较失败，未引用的缓存资产可能留在本机，后续可做定期清理。
- Python `edge-tts` 锁定为 `7.2.8`，其许可证为 LGPL-3.0；本项目以依赖方式安装，没有复制其源码或模型。重新分发环境时应复核锁定版本的许可证及通知要求。在线语音服务的可用性、声音列表和使用条款可能变化；项目不保证其持续可用。
